# Palette data attribution and scope

These files retain source notices. They do not impose one common licence on unrelated sources or certify public redistribution of the whole collection. Registry records retain the original URL, version and source-specific limitations.

- **ggsci 5.2.0**, commit `37b74f85e62680b9d4523b0b4c0d9bfa0403d299`: Nan Xiao and ggsci contributors; iTerm2-Color-Schemes contributors. GPL-3.0-or-later, retained in `ggsci-GPL-3.0.md`. Literal colour tables and continuous generator reference sources are preserved, unexecuted, in `../palette-sources/`. EasyPlot normalizes opaque HEX to six digits and freezes continuous generators at 512 steps as described in the registry.
- **ColorBrewer**: This product includes color specifications and designs developed by Cynthia Brewer (http://colorbrewer.org/). See `../colorbrewer-LICENSE.txt`.
- **viridisLite 0.4.3**: Simon Garnier, copyright 2015. `viridisLite-MIT-copyright.txt` is the installed package's original notice; `R-MIT-template.txt` is the accompanying standard R licence template, kept explicitly as a template.
- **Matplotlib 3.10.9**: retain `matplotlib-LICENSE.txt`, including its upstream attribution. Palette use does not imply endorsement.
- **Paul Tol**: `tol-author-notice.txt` retains the original 2022 copyright and BSD-3-Clause declaration. `BSD-3-Clause-template.txt` is the standard template, with placeholders intact, not an author-supplied full notice. The declaration corroborates six tables from the author's script. Web-only `tol.pale` and `tol.dark` have unresolved redistribution scope recorded individually.
- **Okabe–Ito**: Masataka Okabe and Kei Ito, Color Universal Design, Figure 16. `okabe-ito-author-notice.txt` retains the author's classes/seminars use and attribution wording. A general software/data redistribution licence was not found; none is invented here.
- **Scientific colour maps 8.0.1**: Fabio Crameri (2023), https://doi.org/10.5281/zenodo.8409685. `scientific-colour-maps-MIT.pdf` is the author's original MIT licence; the extracted text is retained separately for searchability. The `scico.*` namespace refers to these author-archive tables, not numerical equivalence with arbitrary R scico interpolation. No data from the R package is copied.
- **cmocean**, tag v4.0.3 / commit `59c35002c3aa5296b65d9646e52604c627441eb6`: Kristen M. Thyng, copyright 2015. Original MIT licence retained in `cmocean-MIT.txt`.
- **CET / cetcolor 0.2.2**, pinned commit `c7e95748040f75f4aef364ad68413c439d590844`: the underlying CET tables are Peter Kovesi's CC-BY-4.0 material; cetcolor's source/data compilation is CC-BY-SA-4.0. Its R package code is GPL-2.0-or-later and is not copied. Full attribution notices are retained in `cetcolor-AUTHORS.txt` and `cetcolor-COPYRIGHTS.txt`.
- **colorspace** HCL palette values were generated with the installed colorspace constructors; no package implementation code is copied. Licence notices are included with the R package distribution.
- **2kil / 东方色**: Frank Lin, site footer copyright 2020, https://www.2kil.com/. EasyPlot treats the traditional colour names and HEX values as public-domain factual data and retains source attribution. This repository uses name/value records and EasyPlot-curated combinations, not the site's layout or artwork. The root MIT licence does not relicense the source website or its presentation. Scheme names/combinations are EasyPlot curation and do not imply source-site or historical endorsement.

No website interfaces, research figures or package installation hooks are part of the palette runtime. Public sharing of the mixed catalogue needs a source-specific licence review.
